# Apurva Kulkarni — SEO Portfolio

A responsive, static personal portfolio website built with HTML and CSS. No dependencies or build tools are required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `seo-portfolio`.
2. Select **Add file → Upload files** and upload `index.html` and `style.css` from this folder. Commit the files to the `main` branch.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. After deployment, visit `https://YOUR-USERNAME.github.io/seo-portfolio/` (replace YOUR-USERNAME with your actual GitHub username).

## Customize

- Update project descriptions in `index.html` with verified outcomes and case studies.
- Add a downloadable resume PDF only if you are comfortable making your contact details public.
- Adjust the colors in `style.css` under `:root`.
- Check all third-party project links before sharing publicly.

## Notes

Project descriptions are illustrative summaries of documented work, not verified performance results. This site is independent of the featured organizations.
